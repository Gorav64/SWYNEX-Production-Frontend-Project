# SWYNEX Task 4 — Deployment & Submission Guide

## 1. Test the project
- Run with VS Code Live Server or another local static server.
- Search for New Delhi, Mumbai or London.
- Check current weather, hourly outlook and 7-day forecast.
- Switch between °C and °F.
- Save a favourite, refresh, and confirm it remains saved.
- Search for a made-up place and check the no-results/error message.
- Check desktop and mobile widths.
- The location button is optional and asks for browser permission.

## 2. GitHub repository
Suggested name: `SWYNEX-Production-Frontend-Project`

Suggested description:
`A responsive live weather dashboard built with HTML, CSS and JavaScript, integrating Open-Meteo APIs with reusable UI components and loading and error states.`

Create a public repository and upload the five files from this folder.

## 3. Deploy using Netlify
1. Sign in to Netlify.
2. Choose Add new site / Import an existing project.
3. Connect GitHub and select `SWYNEX-Production-Frontend-Project`.
4. Leave the build command empty.
5. Set the publish directory to the repository root (`.`).
6. Deploy and wait for Netlify to provide the real live URL.
7. Open the live URL in a private/incognito window and test city search and weather data.

For a manual deploy, drag the extracted project folder (with `index.html` at its root) into Netlify's manual deploy area. Connecting GitHub is recommended for automatic updates.

## 4. Verify
Open both the GitHub repository URL and the Netlify live URL in a private/incognito window. Confirm they work without requesting access. Do not submit a guessed URL.
